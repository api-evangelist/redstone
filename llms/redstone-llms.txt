# RedStone

> RedStone is a modular blockchain oracle infrastructure provider delivering tamper-proof, signed price feeds and off-chain data to smart contracts across 100+ EVM and non-EVM networks. Data is aggregated from 20+ exchanges, signed per data-package, and delivered via Pull (Core), Push (on-chain relayers), and Hybrid (ERC-7412) models. A public read-only HTTP cache/gateway API serves signed data packages and historical prices; no authentication is required and integrity is verified cryptographically.

## APIs
- [RedStone Cache / Price API](https://docs.redstone.finance/docs/introduction): Public read-only prices endpoint — base https://api.redstone.finance (GET /prices?symbol=ETH&provider=redstone).
- [RedStone Oracle Gateway](https://docs.redstone.finance/docs/category/getting-started/): Latest signed data packages — base https://oracle-gateway-1.a.redstone.finance (GET /data-packages/latest/{data-service-id}).
